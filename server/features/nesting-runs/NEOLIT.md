# COMPONENT: Nesting Runs

Stores the digital solutions generated by the nesting algorithms.

## v24 Architecture
- **Digital Bridge**: Connects a `Queue` intent to a specific material layout.
- **Lineage**: Cumulative trace inheriting from Project and Queue.
- **Status**: Governed by `NestingRunMachine` (PROPOSED -> ACCEPTED -> REJECTED).

## Key Workflows
1. **Proposal**: Created automatically by the `Nesting Processor` after algorithm completion.
2. **Review**: Users evaluate the efficiency and layout before accepting.
3. **Acceptance**: Triggers the creation of physical `Sheets` and `Cassette Instances`.

## Data Structure
```typescript
{
  origin: StatusBlock,
  status: StatusBlock,
  lineage: { organizationId, projectId, queueId },
  results: { efficiency, sheetCount, remnantArea },
  layoutData: Object,
  artifactIds: Array<ObjectId>
}
```
